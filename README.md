# Forge — Bodybuilding Journey

A functional single-page MVP for planning and tracking a bodybuilding journey.

## Included
- Dashboard with phase, weight, calories, protein and muscle-volume snapshot
- Push A workout logger with editable sets/reps/load/RIR
- Add exercises
- Nutrition daily log
- Body check-ins with weight/body-fat/waist
- Workout/check-in history
- LocalStorage persistence
- Responsive mobile layout

Open `index.html` directly in a browser, or deploy the folder as a static site.
